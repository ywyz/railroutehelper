## 8. 其他

其他地图共 118 张，主要原因包括：

- 多站但只有零至两类目标车次，例如仅运行 G/D 的高铁区间；
- 无尽模式、自动化、车辆段、货场、线路所或场景型地图；
- 国外铁路、虚构铁路和测试地图；
- 使用外观相似但不属于国铁字头的编号。例如“西沙”地图使用 `1C42`、`2G28`，不能误判为 C/G 车次。

## 9. 测试建议

1. 使用南京枢纽验证完整七字头、多个停车站和复杂股道。
2. 使用上海铁路枢纽北线验证长线路、大站数和 700 车以上时刻表。
3. 使用徐州枢纽验证较小枢纽中的全部七字头。
4. 使用上海西站全天调度验证旧版地图格式。
5. 使用只缺 X 的非常接近地图验证稀有字头缺失时的兼容行为。
6. 将单站和地铁地图作为独立回归集合，不与多站国铁地图使用同一判定标准。
