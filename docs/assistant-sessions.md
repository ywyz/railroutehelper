# 调度会话、告警中心与时距运行图

从 `2.7.0` 起，实时调度助手可以把一次运行记录为版本化 JSONL 会话，并让实时数据
与回放数据经过同一套告警生命周期和时距图投影。所有功能仍然只读取插件的
localhost HTTP 数据，不控制游戏。

## 桌面工作区

主窗口包含四个标签页：

- **实时调度**：保留原有列车列表和每帧即时告警，适合当下调度；
- **告警中心**：显示经过防抖和生命周期跟踪的告警，支持确认、静音和恢复提示；
- **时距运行图**：选择一趟基准列车，以其访问顺序生成车站走廊；
- **会话回放**：记录或打开历史会话，支持暂停、单帧、时间轴、告警跳转和
  `0.5x`、`1x`、`2x`、`5x`、`10x` 播放。

回放模式会停止实时轮询对界面的更新，且默认不触发语音。退出回放后恢复实时模式。

## 会话记录

在“会话回放”页点击“开始记录”选择一个新文件。记录器使用 `CreateNew`，拒绝覆盖或
合并已有文件；程序异常退出时，回放器可忽略最后一条未写完整的 JSON，但中间损坏、
协议版本错误或序号跳跃仍会报错。启用 `gameReady 自动记录` 后，游戏就绪时在
`%LOCALAPPDATA%\RailRouteAssistant\sessions` 自动开始，连续失联 60 秒后结束。

消息使用现有 `RealtimeEnvelope` 外层协议，定义五种 payload：

| messageType | 内容 |
| --- | --- |
| `assistant-session-start` | 会话 ID、开始时间、来源和基准列车 |
| `assistant-train-upsert` | 仅在列车计划或实际/预测事件变化时写入的定义 |
| `assistant-frame` | 游戏时间、连接状态、动态列车状态和结构化告警 |
| `assistant-alert-action` | 确认、静音、取消静音或恢复未读操作 |
| `assistant-session-end` | 结束时间、原因和真实 frame 数量 |

时刻表不会在每秒 frame 中重复写入。桌面端按内容哈希写
`assistant-train-upsert`，frame 只保留动态状态；回放加载时再按消息顺序恢复完整列车
定义，降低长会话的文件和内存开销。

## 告警生命周期

插件为告警输出稳定 `kind`、严重度、主/相关列车 ID、站台、进路轨道、SHA-256
`fingerprint` 和观察时间，同时保留旧版 `level`、`train`、`message` 字段。
fingerprint 不包含中文文案、显示车号、严重度或时间戳，因此文案修改和严重度升级
不会制造新告警。

- `critical` 首帧打开；
- `warning` 连续两个成功帧出现后打开；
- 成功连接的三个帧均未再观察到时标为已恢复；
- HTTP 失联只标为 `Stale`，不作为恢复证据；
- 已恢复后再次发生会创建新的 occurrence ID；
- `Active/Resolved/Stale` 与 `Unseen/Acknowledged/Snoozed` 相互独立；
- 记录的用户操作会在回放中按原顺序重放。

“实时调度”页仍显示未经两帧防抖的即时原始告警；需要确认、静音、历史和恢复状态时
使用“告警中心”。

## 时距运行图

横轴是游戏时间，纵轴是车站。用户选择的基准列车决定站序；只有与它共享至少两个
车站的列车进入同一走廊，反方向列车自动按相反方向投影。第一版不尝试把整个复杂
铁路网强行压成一条站序。

- 灰线：计划到发；
- 彩色实线：已经观察到的实际到发；
- 彩色虚线：最后一个实际点到下一预测点；
- 青色竖线：当前游戏时间；
- 方形/圆形节点：停车/通过；
- 橙红标记：相关活动告警。

绝对游戏秒统一以 `UnixEpoch + gameTimeSeconds` 作为内部绘图坐标，因此可保留
`D+1` 跨日时间。`RelativeTimes=true` 的计划不会被伪造成绝对时刻；图上只显示
相对计划标记，以及由首次观察游戏时间得到的实际到发点。实时图保留最近 7200 个
采样帧（约两小时），完整历史可通过会话回放查看。

## 代码边界

- `RailRouteHelper.AssistantSessions`：会话消息、记录/回放、告警投影和走廊投影；
- `RailRouteAssistant`：结构化告警和 localhost JSON API；
- `AssistantApiClient` / `AssistantSessionAdapter`：HTTP DTO 与会话模型的边界；
- `WorkspaceUi`：四页工作区和记录/回放协调；
- `TimetableGraphControl`：WinForms 双缓冲自绘、缩放、平移和命中测试。

自动测试覆盖协议往返、拒绝覆盖、截断恢复、完整无换行末帧、告警防抖/断线/恢复/
复发、确认和静音独立性、动态字段无损、走廊反向、相对时刻以及实际/预测事件合并。
